# Database audit — findings from the adversarial SQL review

Three independent reviewers (runnability, hostile security, spec fidelity) read the
emitted migration chain and executed it against a real PostgreSQL instance. Every
finding below was reproduced, not merely reasoned about.

Status is tracked in `docs/audit/01-database-findings-status.md`.

## F01 — BLOCKER

/home/user/Qr-kod-menyu/supabase/migrations/20260901009900_privilege_baseline_reassert.sql: public.is_i18n_text(jsonb) is granted to nobody but postgres (final ACL {postgres=X/postgres}).
